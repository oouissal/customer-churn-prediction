# Data

## Dataset

This project uses the **IBM Telco Customer Churn** dataset — a widely used,
realistic sample dataset describing 7,043 customers of a fictional telecom
company, with 21 attributes covering demographics, account information and
subscribed services.

| Property | Value |
| --- | --- |
| Rows | 7,043 customers |
| Columns | 21 (19 features + `customerID` + `Churn` target) |
| Target | `Churn` — `Yes` / `No` (~26.5% churners) |
| Missing values | 11 blank `TotalCharges` for brand-new customers (`tenure == 0`) |

## Source & license

- **Official source (IBM):**
  <https://github.com/IBM/telco-customer-churn-on-icp4d> (file
  `data/Telco-Customer-Churn.csv`)
- **Kaggle mirror:** <https://www.kaggle.com/datasets/blastchar/telco-customer-churn>

The dataset is IBM sample data released for learning/demo purposes. To keep
the repository clean and respect redistribution conventions, **the raw CSV is
not committed to Git** — download it once with the commands below.

## How to obtain the data

Run **one** of the following commands from the project root:

### Windows (PowerShell)

```powershell
New-Item -ItemType Directory -Force -Path data\raw | Out-Null
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv" -OutFile "data\raw\Telco-Customer-Churn.csv"
```

### Linux / macOS

```bash
mkdir -p data/raw
curl -L -o data/raw/Telco-Customer-Churn.csv \
  "https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv"
```

Verify the download: the file must be named exactly
`data/raw/Telco-Customer-Churn.csv`.

## Directory structure

```
data/
├── raw/            <- raw dataset (NOT committed, see above)
│   └── Telco-Customer-Churn.csv
├── processed/      <- train/test splits with engineered features
│                     (generated by `python -m src.train`, not committed)
└── README.md
```

After downloading, the full pipeline is reproducible with:

```bash
python -m src.train      # cleaning -> EDA artefacts -> training -> evaluation
python -m src.predict    # quick interactive prediction on a sample customer
pytest                   # unit tests
streamlit run app/app.py # demo application
```
